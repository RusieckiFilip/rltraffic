⚠️ **The RTG identity, and a correction to the handoff's G6(c).** The agent computes `rtg = target_i − reward_sum`, a
running float64 sum (`SpatialDTAgent.act`, `:745–746`; `current_rtg`, `:608`). The exact check is therefore

**at most 0.50 ULP** (correct rounding), and the step-wise recursion `rtg[t] == rtg[t−1] − reward[t−1]` on 42 — both
false alarms of a check written in the wrong association. The handoff is corrected in the same commit as this note.
