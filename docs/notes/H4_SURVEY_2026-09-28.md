For K=1: low = t, span 1, start 0 -> a one-step window with attention_mask [True], timestep [t]. No K>1 assumption. (Whether the window index set -- `count` -- depends on K: see part 3.)

No positional assumption of K>1.
- Agent rollout: `_window` (:618-660) has an explicit `if history else []` guard for K=1 (:622-627, history = K-1 = 0 -- needed because `list[-0:]` would return everything); the current step's action is PAD (:634-636); `act` takes logits `[:, -1]` (:734) i.e. the last (current) step; buffers are trimmed to the last K entries (:746-763) -> a rolling window of K steps; RTG is decremented by the reward in `info` at each act (:706-708). So a K=1 model conditions on (current RTG, current state, absolute timestep) only -- NOT pure BC: the RTG token and the timestep embedding are still present at K=1 (relevant to how A25 words "degenerate anchor").
