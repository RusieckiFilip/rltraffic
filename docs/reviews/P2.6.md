## 3. D16 (MAJOR, structural) — seed is perfectly confounded with demand block

The five MAPPO seeds cover **disjoint contiguous 40-draw blocks** (seed101→1–40, seed202→41–80, …
seed505→161–200), verified for every tier. **The seed variance component is therefore not estimable
from this corpus at all.** Measured consequence:

```
cf_cologne3 mappo1000 per-seed tier means   [68.1, 74.6, 71.7, 75.4, 83.9]
            maxpressure on the SAME blocks  [107.0, 73.1, 102.8, 111.5, 90.9]
            paired difference per block     [-39.0, +1.5, -31.1, -36.1, -7.0]
```

And MAPPO cells' `std` mixes seed and demand variance while the deterministic baselines' `std` is
pure demand variance — **so the printed ± is not comparable row to row.**

`PREREGISTRATION.md` §8 requires *"Both sources of variance are reported"*. **That is not possible
for MAPPO tiers from this corpus.**
