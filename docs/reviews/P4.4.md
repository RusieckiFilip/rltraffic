## 2. F1 (MAJOR) — a false coverage claim on disk, about the registered fairness constraint

`offline/offline_baselines.py:554-559`, verified in place by the coordinator:

> *"The training loop takes its targets through this function, so the test that pins the behaviour
> guards the path training takes."*

It does not. `gamma` is supplied **at the call site** (`train_iql`, line ~852:
`iql_targets(batch, next_value, gamma=IQL_GAMMA)`), and so is `next_value`. The identical semantic
mutation placed there survives everything:

```
M2-in-helper    horizon absorbing inside iql_targets  -> 1 failed, 57 passed   KILLED
M2-at-call-site horizon absorbing inside train_iql    -> 58 passed             SURVIVED
```

`PREREGISTRATION.md` §7 and the Decisions Log of 2026-07-26 single this constraint out precisely
because getting it wrong *"would hand the MADT an unearned win over its own baselines"*. The packet
reports M2 as KILLED using the one placement that is guarded.

**This is the project's primary error class, in a docstring: a description asserting a guarantee the
artifact does not provide.** No reported number is affected today. The next reader who edits
`train_iql` is the one it costs.

## 3. F2 (MAJOR) — the winning arm rests on reading, not on a test

`test_training_iql_records_the_awr_weight_diagnostic` is the **only** test that runs IQL training,
and it asserts key presence and `0 ≤ x ≤ 1`. Four semantic mutations of the learning rule survive
58/58: `q_target → q` in the V loss, τ-asymmetry reversed, γ=0 at the call site, AWR advantage sign
flipped. Two were retrained in full and evaluated:

```
control:      tau=0.7 gamma=0.99   agreement 0.9501   ATT 102.9339   (reproduces the committed cell EXACTLY)
tau_reversed: tau=0.3 gamma=0.99   agreement 0.9843   ATT 104.0149   delta +1.0810
no_bootstrap: tau=0.7 gamma=0.0    agreement 0.9913   ATT 105.3321   delta +2.3982
```

Both mutants' behaviour-agreement rises to 98–99 %: **they collapse IQL toward BC**, which is exactly
the failure mode the value-learning tests exist to exclude. Sample: 1 seed × 40,000 steps × 20 draws
each.

## 4. F3 (MAJOR, reporting) — the mechanism behind %BC is computable from the artifact and is nowhere in it

Independently confirming and **strengthening** the coordinator's finding:

```
top-20 by return, per seed block: {202: 10, 101: 9, 505: 1, 303: 0, 404: 0}
P(max block count >= 10 | uniform random top-20) = 0.00720      (20,000 permutations)
per-seed TRAINING return    101 -6711.0  202 -6751.8  404 -7199.2  505 -7293.2  303 -7570.2
per-seed HELD-OUT MAPPO ATT 202 103.53   101 103.61   404 106.00  505 106.98   303 107.80
Pearson r(training return, held-out ATT) = -0.991
```

**The two are measured on disjoint draw sets (1–200 vs 1000–1099), so r = −0.991 cannot come from
shared draw difficulty.** With the coordinator's volume check (443.6 vs 446.1 arrivals) and the
MaxPressure-overlap check (4/20), the demand explanation is excluded.

Because D16 makes seed perfectly confounded with demand block, **"%BC" on this corpus is
operationally "clone the best 2 of 5 behaviour policies"** — a different mechanism from a
within-policy return filter, and the paper must say which one it claims. The packet's §8.5 discloses
only *"may be a filter effect … I did not test that"*.
