## 2. N1 (the finding) — a guard whose reference comes from the data it guards

Verified in place by the coordinator at `offline/offline_baselines.py:1038`:

```python
held_out = {int(draw) for draw in payload["held_out_draws"]}
```

The docstring claims invariant 1 is *"no held-out draw enters training — the evaluation pool would no
longer be held out"*. **It cannot provide that**, because the pool it checks against is supplied by
the payload under test.

⚠️ **And it is three instances, not one.** The same function derives `declared_count` from the block
being validated (so "every arm declares 19" is accepted) and `reference_seeds` from the first arm's
own record (so a uniformly wrong seed set passes). **There is also no `rows == T × len(streams)`
check.**

**Nothing is at risk today** — the reviewer checked all 700 stream records against the raw corpus and
no selected stream lies in 1000–1099. **The cost is forward:** the packet offers this function to
P4.6, whose mixture tiers will resample a much larger pool.
