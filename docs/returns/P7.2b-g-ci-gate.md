### Route B failed on its first layout, and the diagnosis is worth recording

The first attempt put the copies in `/tmp/<scratch>/tests/` with `offline/` and `docs/` symlinked.
One test failed: `subprocess.CalledProcessError: 'git rev-parse HEAD' returned 128`. Cause, traced
before anything was changed: `test_the_canary_line_round_trips_through_record_canary` (mine, from
Amendment E1.4) locates the repo root as `DRIVER.parents[2]` and runs git there with `check=True`;
in that layout `parents[2]` was `/tmp/<scratch>`, not a git repository. **The scaffolding was wrong,
not the code** — fixed by putting the copies inside the repo. Recorded as a minor fragility of that
test: it assumes the test file sits at `<repo>/tests/`. True on CI and in every worktree; worth
knowing before someone moves the file.
