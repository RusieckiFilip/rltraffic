### 6.1 Findings about my own code, both of the same shape

**(a) `decomposition_residual` is algebraically `deviation_c1`.** The three terms telescope to
`att_ours − engine_population` while the total is `att_ours − att_engine_call`, so the residual is
`|att_engine_call − engine_population|`. `residual_max` therefore corroborates criterion 1 and
**nothing further**; it is not independent evidence about the decomposition. Stated in the module
docstring and in both artifacts' `what_this_does_not_say`.

**(b) 🚨 M3 SURVIVED, and the reason is analytic rather than a gap in the tests.** Route one of the
identity check (stored terms sum to the stored total) is **implied by** route two (every derived key
recomputed from the constructor fields) **plus `deviation_c1 == 0`**: if route two passes, the stored
terms equal their recomputations, which telescope to `att_ours − engine_population`, which the
zero-deviation assertion forces to equal `att_ours − att_engine_call`. **So no single-field tamper
can kill route one alone.** It is kept — it is a direct statement of the identity that does not
depend on `episode_from_record`, and it fires first with the clearer message — but it adds no
independent evidence, and the docstring now says so. Route **two** is the one with independent power.
`PROJECT_PLAN` §7 requires a check to report its discriminating power; this is that report.
