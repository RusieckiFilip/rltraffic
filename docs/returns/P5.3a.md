## §8.2 — does the trained DT's policy respond to the return prompt?

**It depends entirely on which state distribution you ask about, and the two answers differ by two
orders of magnitude.** I state both and draw no conclusion.

- **On behaviour-policy states (the probe):** barely. Across P4.3's whole 13,000-unit grid the
  greedy action changes on **0.00 %–1.17 %** of decisions, and on two of eight tiers it changes on
  **exactly zero**.
- **On the model's own states (the crosscheck):** **47.22 %** of 360 decisions differ between the
  grid's two endpoints, worth **4.0044 ATT**.

**Which of the two readings does this support?** Per §8.2's instruction I answer with the number and
name the reading. ⚠️ **I do not write "the token is inert."** The brief permits that phrase only when
the flip rate is 0 across the whole grid **and** the TVD is negligible. That conjunction holds for
**`fixedtime` alone** (flip 0.000000 **and** TVD 0.000000 on every intervention). For **`random`** the
flip rate is 0 across the whole grid but the TVD is **not identically zero** (3e-6 … 3.3e-5) — so the
correct statement is *"the logits move by a negligible amount and never cross a decision boundary"*,
which is a different result and is exactly the distinction §4.2 required TVD for. For the remaining
six tiers the prompt is a **weak but non-zero lever on behaviour states** and a **strong lever in
closed loop**.

**This is the direct explanation of P4.3's 0.9026.** That figure is a flat *outcome*; the policy
underneath is **not** flat — it moves 139 of 360 actions between the trained target and target 0 on
draw 1000 alone. Flat outcome, moving policy. The paper must not conflate them.

## §8.3 — the crosscheck: did the live rollout agree with the teacher-forced probe?

**No, and the disagreement is the finding.** `mappo1000` seed 101, draw 1000:

| target | ATT at horizon | decisions |
|---|---|---|
| `0.0` (grid_g0) | 102.0546056260342 | 360 |
| `−13000.0` (grid_g8) | 106.0590182018754 | 360 |

`action_flip_rate = 0.4722`, `att_difference = 4.0044`. Against the probe's `0.0031`/`0.0047` on the
same cell — **~100×**. The mechanism is compounding: teacher forcing pins the state sequence, so it
measures the *instantaneous* sensitivity; in closed loop each flip changes the next state.

**A coincidence I refused to accept without measuring.** Mutation 1's ATT (102.0546056260342) is
bit-identical to the crosscheck's `target=0.0` ATT. Measured directly rather than reasoned about:


Not a defect: a zeroed RTG and a target of 0 drive the **same trajectory** on this draw, and both
differ from the trained target in **38.6 %** of actions.
