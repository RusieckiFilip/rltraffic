## B.5.2 — B.3's stall remedy (code `a59807a`)
- **`episode_watchdog(seconds=600)`** arms `faulthandler.dump_traceback_later(seconds, exit=True, file=sys.stderr)` on entry
  to each episode and cancels it on exit, however the episode ends.
- **`run_with_restarts(command, …, max_restarts=20)`**:
  - Each attempt's output goes to its own log, `<label>.attemptNN.log`.
  - An attempt that exits 1 WITH faulthandler's `Timeout (H:MM:SS)!` header (`watchdog_fired`, the header and exit code
    measured on this interpreter) is restarted.
  - Every restart, and reaching the cap, is a line in `<label>.restarts.log`.
  - Any other non-zero exit stops the run (`failed`), as before.
- **The gate** is now a driver over a `gate-worker` child under `run_with_restarts`:
  - The worker resumes from write-once, atomic per-cell records (`write_gate_record`), each read and checked against its cell
    before anything is rolled (`pending_gate_cells`; a record filed under another cell's name is refused).
  - The driver scores the records only once the worker completes.
  - Inputs are validated (`_gate_cell_inputs`, with the factories built in the worker) before the worker starts.
  - The artifact carries the watchdog's settings and the attempts.
- **Phase B's evaluation** will run under the same two functions when it is written (after M1).
