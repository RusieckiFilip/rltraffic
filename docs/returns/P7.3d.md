### 13.2 An assertion of mine that was wrong as a fact, corrected from the files before its first commit

I asserted *"at least one intersection's lane permutation is not the identity"*, by analogy with hangzhou
(`(0, 1, 2, 3, 6, 7, 5, 4)` there). **On grid4x4 all 16 permutations ARE the identity.** I investigated before touching
the test, because an identity permutation could equally have meant the movement correspondence had degenerated into a
by-position pairing. It has not: the lane INDEX is reversed between the two files (CityFlow's `A1A0_2` serves `r` and
corresponds to SUMO's `A1A0_0`), so **a by-id pairing would be wrong on 128 of 192 lanes** — only the middle lane of
each road keeps its id, 64 / 192 — while the CityFlow corpus's discovery order runs `_2, _1, _0` within a road and
SUMO's is sorted `_0, _1, _2`, so the two reversals cancel position by position. The test now asserts both facts
(`sumo_lane == f"{road}_{2 - k}"` for every lane; every permutation the identity; 64 same-id lanes). **Worth a line in
the paper's CAP discussion:** on this pair *by-position* coincides with the movement key and *by-id* does not.
