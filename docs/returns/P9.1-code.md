## Deviations from the brief (each with a justification)
- **A27's tiers are in NEW registries, not in `TIERS`** (K1): both registries' key sets are pinned by existing tests,
  which may not change.
- **`random_fresh` carries `nan` for its hz1x1 prompt** (K3, Q2): its corpus does not exist before G3; `nan` makes every
  training path refuse it.
- **The A27 arm vocabulary is a new leaf module, `offline/a27_arms.py`, not `offline/corrective_round.py`** (plan C4):
  `method_tier_grid` and `tier_sweep` must consult it, and the campaign module imports both of them.
- **The two registered pre-training checks** (A27(e)'s design facts, A27(d)'s 200 distinct schedules) live in
  `a27_arms` and are called from EVERY training path (`method_tier_grid._run_train`, `tier_sweep`'s two trainers), not
  only from a `declare` step: a check reachable only through one route is a check another route skips. The campaign's
  `declare` (C5) will call the same functions.
- **`offline_baselines train` (P4.4's CLI) does not get `--iql-target-dropout`** (K6): it writes `p4_4_training.json`
  and `<method>_seed<s>.pt` by method name, so an A27 variant there could merge into a registered record.
  `method_tier_grid train --tier mappo1000` is the A27 route. `iql_correction train` is not reused, so it is not
  touched.
- **`--steps 100000` names the arm `_100k`; it does not refuse.** The brief's refusal of "a registered arm name with
  100,000 steps" is implemented where a name is given: `evaluate --method bc --steps 100000` refuses, and
  `a27_arms.refuse_registered_name_at_ceiling` refuses, both tested. In `train`, the name is derived from the flags, so a
  registered name can never reach the ceiling.
- **The fresh reference is the `behaviour` cell of `random_fresh`** on both scenarios (`behaviour@random_fresh`), as the
  registered random reference is `behaviour@random`. The plan's D2 had called it `random_fresh@random_fresh`; the
  existing vocabulary was preferred.
- **C4a touches three source files** (`a27_arms` plus two four-line call sites), against the ≈ 2-per-commit cap: the
  check and its call sites are one change.
