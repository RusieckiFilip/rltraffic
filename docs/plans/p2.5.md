## Objective

Deliver a **fixed-time signal controller** as Tier 1 of the C1 dataset ladder: a deterministic,
stateless policy that cycles each intersection's green phases on a fixed schedule, registered into
`offline.collect`'s `POLICIES` as `"fixedtime"`. Plus the numbers that show it is a faithful,
deployment-realistic approximation of the plan a real city ships (`signal_plan_template.txt`), and
where it lands relative to the P0.2 anchors. **No corpus is collected here** (that is P2.2).

## Design

### D1 — Files (all NEW; nothing frozen touched except allowed edits to `offline/collect.py`)

```
offline/policies/__init__.py            NEW  (package marker)
offline/policies/fixed_time.py          NEW  (controller + parser + provenance helpers)
tests/test_fixed_time_policy.py         NEW  (unit + hygiene + parser)
tests/test_fixed_time_env_mapping.py    NEW  (load-bearing live-env mapping + validation gate)
offline/collect.py                      EDIT (registry entry, --fixed-time-k, 3 manifest fields)
```

`offline/` is **not** in the frozen set (CLAUDE.md §1); `collect.py` edits are the registry integration
the brief mandates. Import direction is one-way: `collect.py` imports from `offline.policies.fixed_time`;
the policy module never imports `collect` (no circular import).

### D2 — Green set and the `a+1` mapping (derived, then verified live)

Compute greens exactly as `AcyclicPhases` does, from public `IntersectionInfo`:

```python
greens_i = [p for p in range(ix.num_phases)
            if float(ix.phase_durations[p]) > TRANSITION_PHASE_MAX_DURATION]  # sorted ascending
```

(import `TRANSITION_PHASE_MAX_DURATION` from the frozen `envs.phase_control`, read-only). The action
index that selects file phase `p` is `greens_i.index(p)`. Fallback to roadlink-based greens when
duration metadata is absent (mirrors `MaxPressureAgent._green_phases`) — real CityFlow/SUMO always
have durations; the fallback only matters for stub envs. **The mapping is asserted against a live env
in §6, never trusted from this derivation alone.**

### D3 — Schedule: stateless, pure function of `info["step"]`

Per intersection, a `cycle_i` (ordered list of green **action indices**) and a shared hold `k`:

```
action_i(t) = cycle_i[(t // k) % len(cycle_i)]        # t = int(info["step"])
```

No internal step counter → cannot drift if a caller skips a step (brief §4.1). No RNG → `rng` arg
unused (the determinism test enforces this).

- **t=0 offset:** cycle index 0 at step 0. Env resets to `greens_i[0]`, so step 0 emits action 0 =
  same green → no spurious initial clearance, and the schedule starts on the shipped plan's first
  green (file phase 1). Declared choice; documented.

### D4 — Plan parser + provenance (`signal_plan_template.txt`)

`parse_signal_plan(text) -> PlanSchedule` (pure function, engine-free):
- line 1 = intersection header; remaining lines = one int phase index per second;
- run-length-decode; the ordered sequence of **distinct green file phases** in the first full cycle is
  the cycle order; record each green's run-length (30 s) and the clearance run-length (5 s).

Factory wiring:
- locate the plan via the CityFlow sim config's `dir` (mirror `collect._cityflow_flow_source`), look
  for `signal_plan_template.txt`;
- **present:** verify the plan's green set equals `IntersectionInfo`'s greens — **mismatch raises**
  (anti-mislabeling); build `cycle_i = [greens_i.index(p) for p in plan_green_order]`. For hangzhou
  this equals ascending `range(num_greens)`;
- record `schedule_source = "shipped_plan"` and the plan file's sha256;
- **absent / malformed:** fall back to §D5, `schedule_source = "equal_split"`, no crash, never
  silently phase 0.

The parser genuinely reads the shipped plan (brief §4.2, §8 Q1). Because hangzhou is equal-split in
ascending phase order, the parsed schedule equals the fallback schedule there; its value is
verification, provenance, and the reported 30 s-vs-`(10k−5)` s deviation. **Uniform-`k` approximates
equal-duration greens only;** if a plan ever had unequal green durations the parser records the
per-green durations so the deviation is visible (hangzhou's are equal — no action needed now).

### D5 — No-plan default (cologne1, cologne3, grid4x4)

Equal split: `cycle_i = list(range(num_greens_i))` ascending, same hold `k`, clearance handled by the
platform. Cycle length `= num_greens_i × 10k` s. Actual per-scenario green counts and cycle lengths
will be measured and reported in the packet/docstring (declared choice, brief §4.3).

### D6 — Control-mode guard (hard error, self-explaining)

Support `acyclic` only. On `acyclic_bounded` / `cyclic` / `resco_cyclic` raise a clear error stating
**why**: the C1 ladder is collected under one control mode; a tier with a different action vocabulary
is not comparable to the others (brief §9 Ruling 3). The message names ladder comparability explicitly
so no one later "fixes" it with a silent fallback.

### D7 — Mask fallback (documented; unreachable under acyclic)

Read `avail_actions` each step. If the scheduled action is legal → emit it. Else hold the current
green's action if legal, else the lowest available action. Deterministic, pure function of
`(step, avail_actions)`. Documented as unreachable under acyclic (every green always available) and
exercised via a stub env in §6.

### D8 — `collect.py` integration

- Register `"fixedtime": _make_fixedtime` in `POLICIES`.
- Add `--fixed-time-k` (int, default `3` provisionally; the ruling on which `k` ships updates the
  default). `_make_fixedtime` reads `args.fixed_time_k` and `args.env_config`.
- **Three manifest fields**, following the `epsilon` precedent exactly (recorded only for the
  `fixedtime` policy, `None`/absent otherwise), via a `fixed_time_provenance(args)` helper in the
  policy module so factory and metadata share one source of truth:
  - `"fixed_time_k"`: `int` or `None`
  - `"fixed_time_schedule_source"`: `"shipped_plan"` | `"equal_split"` | `None`
  - `"fixed_time_plan_sha256"`: sha256 of the plan file when `shipped_plan`, else `None`
  Rationale (brief §9 Ruling 2): without `k` and the schedule source in the manifest, two Tier 1 runs
  with different `k` are indistinguishable from the data — the N5 defect class. Adding named keys
  breaks no test (`test_manifest_contents` asserts named keys only).

## Tests (written first; must fail for the right reason before implementation)

### §6 load-bearing — `tests/test_fixed_time_env_mapping.py` (live CityFlow; self-skips if backend absent, a reasoned skip)

1. **Mapping-in-env:** roll the controller through a real `cf_hz1x1` env (acyclic, `dt=10`); for every
   step assert `info["intersections"][id]["current_phase"] == greens[emitted_action]`. This proves the
   emitted action produces the intended **file** phase in the real env — the test that stops a silently
   mis-labelled Tier 1 corpus.
2. **Mutation is caught:** feed the same checker a mapping offset by one and assert it fails
   (hygiene-compliant `match=` on the assertion message). Demonstrates the test can fail.
3. **Validation gate (brief §9 Ruling 1):** degenerate "hold green 1 all episode" — action 0 every
   step through the env vs. the direct replay harness on the same scenario/draw; assert the two
   `average_travel_time` values agree (tolerance stated). If they disagree the replay number is not
   comparable and k must not be chosen from it.

### Unit / hygiene — `tests/test_fixed_time_policy.py` (engine-free, stub env)

4. **Determinism:** two factory builds, same seed → byte-identical action arrays over N steps.
5. **Cycle structure:** period `= num_greens × k`; each green held exactly `k` consecutive steps;
   every green appears (a controller stuck on one phase fails).
6. **Parser — valid:** correct green order + durations from a synthetic plan; green set verified
   against a stub `IntersectionInfo`.
7. **Parser — malformed/absent:** falls back to equal split; never crashes; never emits phase 0.
8. **Control-mode guard:** non-acyclic mode → error whose message names ladder comparability
   (`match=`).
9. **Mask fallback:** stub env that drops the scheduled action → documented fallback fires
   deterministically.
10. Hygiene: no reasonless skips; every `pytest.raises` has `match=`; no weakened assertions
    (`scripts/check_test_hygiene.sh`).

  phase-control modes" among existing baselines. The phase-control modes supply only the *timing

## Risks

- **Replay/env ATT disagreement** (§6.3): different code paths for `average_travel_time`. Mitigated by
  the validation gate — a mismatch halts k-selection rather than silently mixing pipelines.
- **CityFlow `set_tl_phase` phase indexing** for the replay harness must match roadnet lightphase
  indices (0..8): verified during coding against a one-step probe before trusting replay numbers.
