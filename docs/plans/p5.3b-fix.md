**The per-cell preamble is `evaluate_cell`'s (`offline/nortg_campaign.py:574-643`), element for

**Action recording** (§3.3 of the brief). `_recording_factory(inner, n_actions)` returns a factory
whose `choose_action(env, info)` calls the inner callable, appends `np.array(a, copy=True)` to a
per-episode list and **returns the inner callable's object unchanged** (`return a`, not a copy).
Per episode:

- `n_decisions` — `len(list)`;
- `action_counts` — `list[list[int]]`, one row per intersection, width from

  env's declared action count and **not** data-dependent;

  .tobytes()).hexdigest()`. The docstring states dtype `int64`, C order, shape `(T, n_ix)`.
  ⚠️ Named `action_sequence_sha256`, **never** `episode_sha256` — C6's is over actions *and* rewards
  (`DEFERRED` 57/70/71's class).

**Per-episode record** = `GateEpisode.as_record()`'s 35 keys (26 constructor + 9 derived) plus

**Chunk** `decomp_{method}_{tier}_seed{seed}.json` (e.g. `decomp_dt_nortg_mix50_seed101.json`).
⚠️ The brief writes `decomp_<arm>_<tier>_seed<seed>.json`; a literal `arm` (`dt_nortg@mix50`) would
duplicate the tier and put `@` in a filename. I read `<arm>` as the **method label** and follow the
repo's own `REDERIVED_CELL_TEMPLATE` convention (`cell_{scenario}_{method}_at_{tier}_…`). Disclosed.
Chunk keys: `format_version, method, tier, seed, arm, checkpoint, checkpoint_sha256, draws,
is_complete, n_mismatches, episodes, seconds, seconds_per_episode, tree, runtime`.

**Idempotence — and it is stronger than `p5_3b.sh`'s.** The skip decision lives in **Python**, not in
the shell:

```
skip this cell  iff  the chunk exists AND is_complete AND set(draws) == set(HELD_OUT_DRAWS)
                     AND n_mismatches == 0 AND format_version matches
```

`p5_3b.sh` skips on `[ -f ]` alone, and `assert_probe_cell_is_ablated`'s docstring already records
what that cost: *"the driver skips a tier whose probe chunk exists, so a bad chunk survived every
restart."* **A partial or mismatching chunk is re-run and overwritten.** This is a deliberate,
disclosed improvement on the skeleton the brief tells me to copy.

**Fail-fast.** A cell whose mismatch count is non-zero still **writes** its chunk (the evidence lives
in our own fenced directory) and then exits **non-zero**, so the driver's `|| fail` stops the
campaign on the first bad cell instead of an hour later — and the chunk cannot be skipped on restart
because of the predicate above.

**The fence — `assert_decomposition_writable(path) -> Path`.** Default-deny, modelled on
`nortg_campaign.assert_writable` (`:309-342`) and **a separate function with a separate name**
(`DEFERRED` 57's class — not a second `assert_writable`). Its own allow-list is
`("p5_3b_decomp", "SHA256SUMS_p5_3b_decomp.txt")` and **nothing else**, so `output/p5_3b/x`,
`output/p8_4b_rederivation/x`, `output/p4_dt/x` and `output/never_seen/x` are all refused —
including `p5_3b`, this campaign's own predecessor. Matching is on whole path components of
`Path(path).resolve()`, never on a string prefix. Raises `ValueError`.

### 4.2 🔒 `report` — the load-bearing check and the barrier

`report` reads all 30 chunks, then validates **everything** before the first byte is written.
`write_json_atomic` refuses (never creates) a missing parent directory, and `report` calls no
`mkdir`. On any refusal `docs/data/p5_3b_decomposition.json` does not exist afterwards.

Validation, in order:

1. **Completeness.** Exactly 30 chunks; each with exactly the 100 `HELD_OUT_DRAWS`; 3,000 rows,
   no duplicate `(method, tier, seed, draw_id)`. *"Compared nothing" must never read as "found no
   differences"*.
2. **Committed identity — recomputed from the sources, not read from the chunk's flag.** For
   `dt_nortg`, the committed pair is read from `docs/data/p5_3b_nortg.json:episodes`; for `dt`, from
   `nortg_campaign.rederived_dt_episodes(tier, …)` (which itself runs
   `assert_rederived_matches_committed`). `report` asserts, per episode, **all four** of
   `att_engine_call == committed_att_engine`, `att_ours == committed_att_ours`,
   `committed_att_engine == <source value>`, `committed_att_ours == <source value>`, under `==`.
   ⭐ **The chunk's own `reproduces_committed` is never trusted** — that is P8.4b's flag-trusting
   shape, and the review found it once already.
3. **Gate 0's own criteria.** `deviation_c1 == 0.0`, `deviation_c3c == 0.0`,
   `decomposition_residual == 0.0`, on every one of the 3,000 (with §2.7's reading attached).
4. **The identity, checked on the STORED terms.**
   `term_population + term_clock_origin + term_cadence == att_ours − att_engine_call`, exactly,
   computed from the values in the file. ⭐ **And a second, independent route:** every stored derived
   key is compared against `episode_from_record(row)`'s recomputation from the constructor fields —
   which ignores the stored derived keys entirely. A tampered `term_*` fails route one; a tampered
   `att_reference_*` fails route two.
5. **Contrast consistency.** Per tier, `|(Δ_ours − Δ_engine) − (Δpop + Δclock + Δcad)| < 1e-9`
   against `docs/data/p5_3b_nortg.json:comparisons.<tier>.by_definition` (the three values in §1.2).
   ⚠️ **`==` is deliberately NOT used here and the docstring says why:** the two sides reduce the
   same 3,000 floats in different summation orders, so exact equality would condemn a correct
   implementation. **Per episode the identity is exact and is checked exactly** (item 4).

Only then: `write_json_atomic(payload, out_dir / "p5_3b_decomposition.json")`.
