### 4.2 `preflight` (brief §3.1) → `docs/data/p9_3_preflight.json`; writes nothing else
1. **Canary + power** (`PROJECT_PLAN` §7, 2026-09-13): `offline.transfer_calibration.canary_seconds` + `check_canary` (reference
   ≈ 0.9 s, ceiling 2.0 s, `−32648.0 / 247.75089149261333` under `==`) at the start and at the end, with
   `offline.compute_latency.power_block()` beside each. A throttled canary means no rate from that run is quoted.
2. **hz4x4 facts:** the env built through `experiments.envs.make_env` on draw 0 — 16 intersections, `Utils.infer_action_counts`
   = 8 on each (the brief's assertion; refusal otherwise); the source's 2,983 single insertions; the main tree's and this
   tree's `configs/sim/cityflow4x4.json` byte-identical (sha256).
3. **CityFlow seconds:** MaxPressure (`dt_gate._maxpressure_factory`), draws 0 and 1 (materialised configs), 360 steps, engine
   seed 1000, the grid MaxPressure manifest's settings (`dt_gate.env_settings_from_manifest`). Recorded: seconds and decision
   count only — no ATT, no return (the pre-flight produces no outcome number).
4. **MAPPO seconds per training episode:** the REAL teacher config loaded by `experiments.config.load_config`, its hz4x4
   `EnvSpec` with `train_episodes` replaced by 20 (`dataclasses.replace`, nothing retyped), trained by the frozen
   `experiments.runner._train_agent` in **five concurrent processes, one per seed** (the teachers' regime: `--workers 5`, one
   torch thread each through `experiments.runner.limit_torch_threads`, called first in each child). Per process:
   seconds / 20. After training, each child calls the trained agent's `act` on an `info` from the COLLECTION env (the grid
   MaxPressure manifest's settings) — the C8 global-feature width check, so a metric-set mismatch between training and
   collection is found now and not after a day of training.
5. **Projection:** per seed `1000 × max-over-processes(seconds per episode)`; with 5 workers on 16 cores the five seeds run
   concurrently, so the projected wall-clock is that figure. **GO iff ≤ 86,400 s** (A27(i)'s one-day rule). Beside it, the grid's
   records read from their artifacts (MAPPO@1000 median 3,462.55 s per seed from `p8_2_compute.json`; MaxPressure 1.16 s, the
   coordinator's figure quoted by the brief, marked as quoted). No cross-session ratio is formed (§7, 2026-08-03 rule).
6. **Workers:** MAPPO 5 (one per seed). Corpus: 1, sequential, abort on first failure (`recollect_v11`'s campaign rules), because
   the eight collection runs total ≈ 1,640 episodes at ≈ 1.3 s plus MAPPO inference — minutes, not hours.

### 4.3 `k-sweep` (D5, brief §0) → `docs/data/p9_3_fixed_time_sweep.json`, BEFORE any collection

committed artifact, never from a flag.
