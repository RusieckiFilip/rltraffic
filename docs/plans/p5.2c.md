## 3. The registered text the scorers implement — quoted, located, and how each is scored

### 3.0 Common scoring — `p5.2.md:407-412`
> **Scoring, common to all.** Primary metric `att_horizon` (A1). Paired unit = per-draw mean over the 5 seeds across the 100
> shared held-out draws (`dt_gate._per_draw_means`). Interval = the 95 % CI of the mean paired difference (`mean_ci95`,
> `ddof=1`, `1.96 σ/√n`). Lower ATT is better. Every outcome is one of **HELD / FAILED / NOT RESOLVED**, and `NOT RESOLVED` is
> always reported with the CI width rather than folded into either neighbour.

**Implemented as:** for a contrast `left − right` on a tier: both cells refused unless complete (V5) and covering the identical
`(seed, draw)` grid; per-draw means by `dt_gate._per_draw_means` on `iql_correction.episodes_from_rows(rows,
value_key=definition)`; differences in ascending draw order; `mean_ci95`; low/high = mean ∓ half-width; width = high − low. The
interval outcome for a predicted-negative quantity is `spatial_mixing._outcome_from_interval(low, high)`; for a predicted-positive
one, the same function on `(−high, −low)`. Beside every contrast: `tier_sweep.per_seed_block(left, right, left_name, right_name,
metric=definition)` (D9, P5.1's workers), `att_rederivation.contrast_discriminability` on the per-episode values (P8.4b's binding
rule of 2026-08-31), and `exactly_zero` (every per-draw difference `== 0.0`), reported as *exactly zero (identical episodes)*.
**The tie rule (`:606-609`, quoted in 3.3) applies to every ordering.** Under the brief's ruling a statement registered *"on all
three/four tiers"* is HELD iff every tier is HELD, FAILED iff any tier is FAILED, NOT RESOLVED otherwise.

### 6.5 The barrier (`PROJECT_PLAN` §7:1345)
Every input check runs first; then the out path is refused if its resolved form lies under the resolved `--output-root`, under any
directory whose ancestor chain holds `SHA256SUMS_p5_2.txt` (a real output tree, whatever `--output-root` says — P5.2b's B1.6(a)
test), equals any input file, is not `.json`, has a missing parent directory (nothing is created), or **already exists
(write-once, as P5.2b's `write_report`)** — via `tier_sweep.assert_writable` against `protected_roots_from([output_root, *input
files])`. Only then are the bytes serialised in memory, written to a dot-temporary in the same directory and moved by
`os.replace`; the temporary is removed if anything raises. A refused run leaves no file, no temporary and no directory, and an
