## 1. G1 — split the failing test

**(a) CI-runnable, no gate.** `test_an_unreadable_chunk_is_moved_aside_even_when_the_re_roll_cannot_proceed`:
plant `[]` as `probe_draw_0201.json`, call `run_sumo_probe([201], out_root=<an empty tmp dir>, ...)`,
and assert **both** halves — the `FileNotFoundError` naming the missing configuration *and* that the
bad chunk is now in `failed/`, byte-identical, with the original path gone. `out_root` is a parameter,
so this test never reads `DRAWS_ROOT` and runs everywhere, CI included.

**(b) The existing full re-roll, gated on the draw it actually consumes** — 201, not 5. Keeps the
`_roll_one_episode` monkeypatch and the `chunk_is_reusable(fresh)` assertion, which are the half that
needs the band on disk.

⚠️ The brief's warning is the point: gating this on `_draws_available()` as it stands would name
**draw 5**, and on CI neither draw exists, so the wrong predicate would pass *by accident*. G2 is
what makes the right predicate expressible.

## 2. G2 — a gate names the artifact its test consumes

`_draws_available()` in **both** files gains a **required** `draw_id` parameter. Required, not
defaulted: a default is exactly the thing that let a draw-5 predicate stand in for a draw-201
dependency. Every call site then names its draw, and the `reason=` string names it too, so `-rs`
output on CI says which artifact was missing.

## 3. G3 — prove it in CI's condition

Because `DRAWS_ROOT` and `OUTPUT_ROOT` are absolute paths into the main tree, a worktree proves
nothing. **Two independent reproductions**, because one mechanism agreeing with itself is not
evidence:

* **Route A — monkeypatching before collection**, via a single-file plugin passed with `-p`. The
  plugin patches `pathlib.Path.is_file` to report **every path under the two hardcoded roots**
  absent, and is imported before the test modules, so the `skipif` predicates — which evaluate at
  import — see CI's filesystem. Nothing outside those two prefixes is affected, so `tmp_path`,
  `docs/data/` and `offline/` behave normally, exactly as on CI.
* **Route B — the literal instruction.** Copy both test files into a scratch tree with **only** the
  two constant lines rewritten to an empty temporary directory, `diff` the copies against the
  originals to prove exactly those lines differ, symlink `offline/` and `docs/` so `REPO_DATA` and
  `DRIVER` resolve as they do on CI, and run.

Both must give **0 failures**. Both skip counts must agree with each other, and the set of skipped
test names must be identical. A **control** is run first: the same two files unpatched, which must
show **0 skips** — that is the finding of Amendment G restated as a measurement.
