```python

# -> {"subject", "seed", "path", "file_sha256", "sha256_checked_against", "deferred_56"?}
```

  refusal; a manifest absent is recorded as absent.

* **G2 — the demand identity is two digests, not one:** `config_sha256` (`noteleport.sumocfg`) **and**

  leaves the cfg's digest unchanged, and ρ pairs three cells that must provably share one demand.

All four digests are stored in the chunk **and re-derived from disk on resume** — `chunk_is_reusable`
recomputes the checkpoint's, the cfg's and the routes file's sha256 and compares with the chunk's
stored strings. A stored verdict is not evidence
(`transfer_calibration.chunk_is_reusable:232-267`, `nortg_decomposition:469`).

### 2.3 The env for a cell, and C8's refusal (E3c)

```python
def env_for_cell(cell, *, out_root, halting_check) -> Any     # AlignedEnv | observer SumoEnv

```

* `kind == "dt"` → `aligned_observer_env_for_draw(SCENARIO_KEY, draw, out_root=…, halting_check=…)`
  (`aligned_env.py:213`) — observed **and** aligned;
* `kind == "anchor"` → the same construction **without** the wrap. **G3 overrules the plan's first
  draft here:** *"six lines mirroring `aligned_env.py:247-260`"* is a second copy of the construction,
  and two copies diverge silently the day a setting is added to one. Instead, `offline/aligned_env.py`
  is refactored so there is ONE path —
  `observer_env_for_draw(scenario_key, draw_id, *, arm, out_root, sentinel_out_dir, halting_check)`
  returns the **unwrapped** observer, and `aligned_observer_env_for_draw(...)` becomes
  `AlignedEnv(observer_env_for_draw(...), declared_alignment())`. T4's contract over the aligned env is
  unchanged and is re-run to prove it. I do **not** reach through `AlignedEnv._env`, which is the
  access the `recorder` property exists to stop.
* `assert_env_matches_cell` refuses an anchor cell whose env is an `AlignedEnv` **and** a DT cell whose
  env is not, by `isinstance`, with the measured reason in the message (`align_info` drops outgoing
  lanes; MaxPressure's pressure is a difference over SUMO lane ids → `KeyError: 'road_1_1_2_0'`,
  `algorithms/max_pressure.py:142`). This is C8's *"the cell builder's explicit refusal"*, and it is
  called by `run_cell` on every cell, so a future change to the factory cannot bypass it.
* **`halting_check` is passed at CONSTRUCTION, never assigned afterwards.** `AlignedEnv` forwards
  attribute *reads* through `__getattr__` (`aligned_env.py:155-169`) and defines no `__setattr__`, so

  untouched — P7.1's `_select_halting` (`sumo_att_reference.py:1292`) assigns on a bare env and is not
  a pattern that survives the wrapper. C2's subset is therefore `halting_check=(draw_id == HALTING_CHECK_DRAW)`
  at build time.
