## 0. The one-paragraph summary

Train three offline baselines — behaviour cloning, %BC (top-10 % of trajectories by return) and
independent per-intersection IQL — on the **same `cf_hz1x1` `mappo1000` tier** the P4 Decision

margin **δ = 0.6263 ATT**, the recovered-fraction reporting, the forecast and the IQL sweep decision
are all fixed in this file **before the first gradient step**.

| evaluation action selection | greedy (`explore=False`) argmax over masked logits | the DT's declared evaluation path |

**The plateau criterion** (`plateau_reached`, 2000-step windows, tolerance 0.05) is computed and
recorded per seed as a **diagnostic only**. It cannot move the reported checkpoint: the reported
model is the one at step 40,000, and nothing else.

### 3.2 BC

Trained on the **identical batches the DT saw**, through the **identical `action_loss`** with
`ignore_index = -1`, over **every valid position** of every window. The only difference from the DT
is the architecture: a per-position MLP that sees `s_k` alone — no other position, no return-to-go,
no timestep embedding. Batch **64 windows** (= up to 1280 loss positions).

Capacity: ≈0.4 M parameters against the DT's 0.65 M; the difference is exactly the attention
weights (`qkv` + `proj`, `4d²` per layer). Reported with the parameter counts measured, not assumed.

### 3.3 %BC

Identical to BC in every respect except the training subset: the windows belonging to the **top 10 %
of (episode, intersection) streams by return**. Selection is deterministic and declared:
sort by `(-return, dataset_dir, episode_file, ix_id)` and keep `ceil(0.10 × N_streams)` = **20 of
200** streams (F4 shows the boundary is not a tie: −6419.0 against −6449.0).

**Normalisation statistics stay the full-training-split ones**, so the filter is the only difference
between BC and %BC. They are training-split statistics either way, so no leakage is introduced.

### 3.4 IQL — independent per intersection

| Key | Value | Provenance |
|---|---|---|
| expectile `τ` | **0.7** | published IQL, D4RL **locomotion** |
| AWR temperature `β` | **3.0** | published IQL, D4RL locomotion |
| discount `γ` | **0.99** | published IQL |
| target-network Polyak | **0.005** | published IQL |
| AWR weight clip | **100.0** | published IQL |
| reward scale | **`1000 / (max_return − min_return)` on the TRAINING SPLIT = `1000/4229` = 0.23646252069047055** | IQL's own published locomotion normalisation, applied to this corpus's measured returns (F4) |
| batch | **1280 transitions** | equalises `(s, a)` pairs consumed per gradient step with the DT and BC (64 × 20); the published value is 256, and the deviation is declared here with that reason |

**Losses.**
```
L_V = E[ |tau - 1{u < 0}| * u^2 ],        u = Q_target(s, a) - V(s)
L_Q = E[ ( Q(s, a) - (r + gamma * V(s')) )^2 ]          <-- no done term anywhere
L_pi = -E[ min(exp(beta * (Q_target(s,a) - V(s))), 100) * log pi(a | s) ]
```

⚠️ **The registered fairness constraint (`PREREGISTRATION.md` §7, Decisions Log 2026-07-26):**
`terminated` is hardcoded `False` and every episode ends by time-limit truncation, so **IQL
bootstraps through the boundary**. `done` is `False` at **every** transition including the last, and
the last transition's target is `r_{T-1} + γ·V(s_T)` where `s_T` is the corpus's observation row `T`.
Treating the horizon as absorbing would cause systematic value underestimation near episode end and
would hand the DT an unearned win. Pinned by tests T2, T3 and T3b.

**Provenance caveat carried into the packet (brief §7 Q3/Q4):** these are continuous-control MuJoCo
values transplanted onto a discrete 8-phase action space, with a normalisation convention applied
outside the domain it was defined for. Also: IQL's 1280 transitions are **independent** while the
DT's and BC's 1280 positions are **correlated within 64 episodes**, so this equalisation slightly
favours IQL — the conservative direction for our claim, and said so in the packet.

### 3.5 THE IQL SWEEP DECISION — **DO NOT SWEEP**, decided before the first gradient step

Brief §8.3(b) authorises a bounded sweep over `τ` and `β` only, ≤6 configs, **selected on
training-split expectile/TD loss**. §9.2 requires the choice and its reason to be written here first.

> **Decision: no sweep. IQL ships with the published values above, unswept, and is reported as
> untuned.**

**Reason — the authorised selection criterion cannot rank either parameter it is authorised to rank,
and this is an analytic fact about IQL's objectives, not a claim about any result:**

1. **`β` does not appear in the value losses at all.** It enters only the AWR policy loss. A
   criterion computed on the expectile/TD loss is therefore **exactly insensitive to `β`** —
   selecting on it would be a choice dressed as a measurement.
2. **Selecting `β` on the *policy* loss is provably degenerate.** `L_pi` is a weighted negative
   log-likelihood whose weights `exp(β·A)` shrink toward 1 as `β → 0`, so the loss decreases
   monotonically with smaller `β`; the criterion would select the smallest `β` in any grid. At
   `β → 0` every weight is 1 and **IQL's policy extraction becomes plain BC** — the sweep would
   collapse the IQL arm into the BC arm.
3. **`τ` defines the expectile loss**, so `L_V(τ = 0.7)` and `L_V(τ = 0.9)` are values of two
   different objectives and are not comparable. Substituting Q's TD error to dodge that is worse: a
   smaller `τ` makes `V` easier to fit and the TD error smaller nearly by construction, so the
   criterion is biased toward `τ → 0.5`, the SARSA-like regime IQL exists to escape.
4. Selection on evaluation return is forbidden (D5 / `PREREGISTRATION.md` §6.1), and no offline
   policy-evaluation estimator exists in this repo to replace it. Building one is a separate task.

**What ships instead of a sweep**, both computed on training data only and therefore selecting
nothing:
- the **binding sentence** of §8.3(a), in the same sentence that reports the number;
- a **degeneracy diagnostic** recorded in the training artifact: the distribution of the AWR weights
  `exp(β·A)` (mean, quantiles, fraction clipped at 100, fraction below 0.01, effective sample size
  `(Σw)² / Σw²`), plus the learned policy's agreement with the behaviour action on the training
  split. If the transplant degenerated, this says so mechanistically, which a sweep would not.

If the coordinator later wants a swept IQL, the criterion problem has to be solved first; that is
recorded as an open question, not resolved here.

### 3.6 The canonical checkpoint digest (`DEFERRED` 29, introduced here)

`canonical_state_dict_digest` = sha256 over the `state_dict` tensor bytes in **sorted key order**,
which is independent of the filename (`torch.save` names the zip root after the output file) and of
the provenance block. **Every determinism claim in this task is made with it.** The file sha256 is
kept beside it for what it does prove — transport integrity. Both go into every checkpoint record in
the artifacts.

## 4. Registered forecasts — written before the first gradient step (brief §7 addition 3, §8.2)

**Primary, falsifiable in both directions:**

> **BC lands within δ = 0.6263 ATT of the DT on the paired held-out mean.**

*Reasoning:* the DT's final training cross-entropy is 0.013–0.024 (F10) — it has very nearly
memorised the behaviour policy's action distribution. A per-position MLP trained on the identical
batches through the identical loss should reach a comparable fit, so if the DT's held-out margin came
from imitation quality alone, BC should reproduce it. **A confirmed forecast here is itself a
finding**: it would mean the DT's margin comes from something other than better imitation.

**Secondary, labelled as such, also falsifiable:**

> **%BC lands within δ of BC.** The tier is expert-only and narrow (returns −9991 … −5762, a 1.73×
> spread), so its top-10 % slice is unlikely to be qualitatively different behaviour.

**No forecast is registered for IQL.** I have no basis for one: the hyperparameters are transplanted
from a different domain and I decline to guess, which is more honest than a prediction I could
rationalise either way afterwards.

The per-draw unit for pairing is the **mean over the 5 training seeds**, matching P4, so seed and
draw are crossed rather than nested.

### 5.2 Statistics

Mean ± 95 % CI per cell via `mean_ci95` (`1.96·sd/√n`, `ddof=1`) and `att_horizon` **plus
`vehicle_count` at the horizon plus the draw ids, unconditionally** (A5). Paired Wilcoxon over the
100 shared draws via `wilcoxon_signed_rank`, and **beside every p-value** (`PREREGISTRATION.md` §8):

- matched-pairs **rank-biserial** `r = (W₊ − W₋)/(W₊ + W₋)`,
- the **mean paired difference ± 95 % CI half-width and the CI's WIDTH** (brief §7 addition 2:
  "contains 0" is a failure to reject, and the width converts it into *no difference larger than
  ±X found*),
- the median paired difference and **wins / losses / ties**.

### 5.3 The verdict — `PREREGISTRATION.md` A6, three registered branches and one it does not name

`δ = 0.6263 ATT` (A6's declared literal). Differences are `d_i = ATT_DT(i) − ATT_arm(i)` over the
100 shared draws; lower ATT is better, so `d < 0` means the DT is ahead.

| CI(d) | verdict |
|---|---|
| entirely within `[−δ, +δ]` | **the baseline matches the DT** |
| entirely below `−δ` | **the DT is genuinely better** |
| straddling either bound | **inconclusive at this power**, reported with the CI width |

**A6 names three branches. A fourth is arithmetically possible — CI entirely above `+δ`, i.e. the
baseline beats the DT by more than δ.** Under A6's literal wording that lands in "straddling ⇒
inconclusive", which would be wrong: it is a decisive result in the other direction. I compute all
four mechanically, report the three registered ones verbatim, and **if the fourth occurs I report it
separately and flag the asymmetry as an open question** rather than silently reclassifying it.

Two mechanical guards on the constant itself: A6's literal `0.6263` is used, the full-precision
derivation `0.6262756469347…` is recorded beside it, and the report **asserts no CI endpoint lies
within 1e-3 of ±δ**, so the rounding can never be load-bearing.

### 5.4 The recovered fraction — unconditional, every branch, every arm (A6 clarification, §9.1)

```
recovered_fraction = (ATT_mappo1000 − ATT_arm) / (ATT_mappo1000 − ATT_madt)
```

reported beside the verdict for **BC, %BC and IQL in every branch**, because δ equals the effect
under study: a baseline landing 0.5 ATT worse than the DT sits inside ±δ and returns *matches* while
having recovered only 20.2 % of the DT's margin over its own behaviour policy.

**Double-computed by the identity** `recovered_fraction = 1 − mean(d_arm − d_madt)/δ`: the first
route uses three arm means, the second uses the paired per-draw differences. The two are the same
quantity through different arithmetic and the report asserts their agreement.

### 5.5 What the DT-minus-baseline difference is NOT (brief §7 addition 1)

**DT − BC is a combined difference: attention/context PLUS return-to-go conditioning PLUS the
timestep embedding.** The packet states it that way and never as "sequence modelling adds X".
Decomposing it is P4.3's (RTG) and P5.3's (`no-RTG`, context length K) registered work.

### 5.6 The binding IQL sentence (brief §8.3(a))

Whatever the number, it is reported as: *"MADT outperforms an untuned IQL configured from published
D4RL-locomotion values; this is not evidence that MADT outperforms IQL."* — **in the same sentence
that reports the number**, not in a caveats section.

## 8. Campaign integrity (brief §7 Q8's conditions)

Long jobs run in the background **from this session**, on the P4 precedent and at the same scale, and
each individual job is kept under ~30 minutes (Gate A ≈ 22 min; each evaluation arm ≈ 10 min); any
job that would exceed it is handed to the user's `tmux` instead. Every campaign **aborts on the first
failure** and **ends with an assertion that completed runs equal runs requested**, with the expected
`(arm, seed, draw)` triples enumerated up front. Artifacts are written only after that assertion
passes, atomically, into an existing directory — a refused run creates nothing.

## 10. Risks, limitations and open questions

1. **BC may match or beat the DT.** Registered outcome (`PREREGISTRATION.md` §10); reported first,
   before any interpretation, and the paper's weight moves to the ladder and shift findings.
2. **An untuned IQL that loses supports no claim about IQL.** Bound by §5.6 in the same sentence as
   the number.
3. **The DT − baseline difference is combined** (§5.5) and is never reported as a sequence-modelling
   effect.
4. **Single scenario, single backend, one intersection, expert-only tier** — the narrowest state
   coverage in the ladder. Nothing here bears on off-distribution behaviour.
5. **A second reader of episode files is introduced for IQL** — `load_episode`, the format's single
   sanctioned reader, because the window dataset structurally cannot yield row `T` (F12). Approved in
   brief §7 Q1; guarded by T3 **and** T3b, the second of which is the only check that sees the row at
   risk.
6. **Open question for the coordinator:** A6 names three verdict branches and not the fourth (§5.3).
